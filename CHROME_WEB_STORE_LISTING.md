# Chrome Web Store Listing — Color Palette Helper

## Extension name

Color Palette Helper

## Summary

Compare colours on any webpage with a customisable personal palette dial that follows your cursor.

## Detailed description

Color Palette Helper makes it easier to compare colours while browsing online. Activate a circular colour dial over any webpage, move it over an image or product, and visually compare the colour beneath the cursor with your personal palette.

The transparent centre keeps the page visible while your palette colours surround it, making direct visual comparison simple and unobtrusive.

Key features:

- Cursor-following colour palette dial with a transparent centre
- Create and manage multiple personal palettes
- Import and export palette files for backup or sharing
- Reorder colours using drag and drop
- Mark stronger colours so they extend beyond the dial edge
- Adjust dial size, ring width, opacity and rotation
- Switch palettes quickly from the toolbar icon's right-click menu
- Includes a seven-colour Rainbow example palette
- Works locally without accounts, advertising or cloud services

Click the toolbar icon to show or hide the dial. Press Escape to close it. Right-click the icon to change the active palette without opening settings.

Color Palette Helper is intended as a visual comparison aid. It does not analyse products, identify garments, guarantee colour accuracy, or replace a calibrated display or physical colour swatch.

## Privacy statement

Color Palette Helper does not collect, transmit, sell or share personal data. It contains no analytics, telemetry, advertising or remote services. Palettes and preferences are stored locally in the browser. The extension does not capture screenshots, record browsing history or upload webpage content.

## Single purpose statement

Color Palette Helper provides a movable personal colour-palette dial for visually comparing colours on webpages.

## Permission explanations

### activeTab

Allows the dial to run on the current webpage only after the user clicks the extension toolbar button.

### scripting

Adds the non-interactive colour dial to the current webpage when requested by the user.

### storage

Stores palettes, the selected palette and dial settings locally in the browser.

### contextMenus

Adds the palette-selection submenu shown when the user right-clicks the extension toolbar icon.
